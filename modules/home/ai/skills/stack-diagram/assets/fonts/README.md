# Bundled fonts

| File | Font | License |
|---|---|---|
| `Geist.woff2` | Geist 1.800 (variable, subset) | SIL OFL 1.1 — see `OFL-Geist.txt` |
| `JetBrainsMono.woff2` | JetBrains Mono (variable, subset) | SIL OFL 1.1 — see `OFL-JetBrainsMono.txt` |

Both files are Latin subsets of the upstream fonts in WOFF2, unchanged otherwise (`Geist.woff2` is the Fontsource Latin build). `build.py` embeds them into each generated diagram as data URIs.
